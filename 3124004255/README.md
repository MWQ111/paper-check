# 论文查重程序（Paper Plagiarism Checking）

## 一、项目简介

本项目是一个基于 **TF-IDF + 余弦相似度** 算法的论文查重程序。

程序接收「原文文件」与「抄袭版论文文件」两个输入，计算两者之间的重复率，
并将结果以**两位小数**的浮点数形式写入指定的答案文件。

支持中文与英文混合文本，能够识别同义改写、语序调整等常见抄袭手段。

**样例**

| 类型 | 内容 |
| --- | --- |
| 原文 | 今天是星期天，天气晴，今天晚上我要去看电影。 |
| 抄袭版 | 今天是周天，天气晴朗，我晚上要去看电影。 |
| 输出重复率 | `0.67` |

```bash

```

三个参数均为文件路径，顺序固定，缺一不可：

| 参数 | 说明 |

| 抄袭版论文文件 | 待比对的抄袭版论文文本文件 |
| 答案文件 | 重复率输出目标文件，程序会自动创建或覆盖 |

| 退出码 | 含义 |

### 4.4 编码说明

程序默认以 **UTF-8** 读取输入文件；若解码失败，会自动回退以 **GBK** 重试，
以兼容 Windows 下常见的 GBK 编码文本文件。答案文件统一以 UTF-8 写出。

## 五、算法说明

程序的处理流程为：**读取 → 清洗 → 分词 → 构建 TF-IDF 向量 → 余弦相似度 → 输出**。

### 5.1 文本清洗

使用正则去除标点与符号，仅保留中文字符、英文字母、数字与空白，
并将英文字母统一转为小写，使 `Hello` 与 `hello` 视为同一个词。

> 说明：空白字符予以保留。英文依赖空格划分单词边界，若清洗阶段一并去除，
> `hello world` 会被合并成 `helloworld`，无法按单词切分。中文分词基于正则提取，
> 空白会被自然忽略，因此保留空白不影响中文切分。

### 5.2 分词策略

| 语言 | 策略 |
| --- | --- |
| 英文 | 按单词切分，正则 `[a-zA-Z]+` |
| 数字 | 按数字串切分，正则 `[0-9]+` |
| 中文 | 按**单字**切分 |
| 中文补充 | 相邻两字组成 **2-gram**，如「今天」→ `今`、`天`、`今天` |

单字与 2-gram 同时入袋，既保留单字的召回能力，又通过 2-gram 增强短语的区分能力，
从而能识别「星期天 → 周天」这类同义改写。

分词结果通过**生成器 `yield` 惰性产出**，无需一次性构造大列表，
在长文本场景下显著降低内存占用。

### 5.3 TF-IDF 向量

- **TF（词频）**：单文档内归一化词频，即 `词出现次数 / 文档词元总数`
- **IDF（逆文档频率）**：由参与比较的两篇文档共同计算

  ```text
  idf = ln((N + 1) / (df + 1)) + 1
  ```

  其中 `N = 2`（两篇文档），`df` 为该词出现的文档数。

  > 此处对 IDF 做了平滑。若使用未平滑的 `ln(N / df)`，两篇文档共有的词元
  > 因 `df = 2` 会得到 `ln(1) = 0` 的权重而被整体忽略，导致相似文本被误判为不相似。

### 5.4 余弦相似度

```text
similarity = (A · B) / (|A| × |B|)
```

- `A · B`：两向量点积
- `|A|`、`|B|`：两向量的欧几里得模长
- 任一向量为空（即文档无有效词元）时，直接返回 `0.0`，避免除零错误

结果取值范围为 `[0.0, 1.0]`，越接近 1 表示重复度越高。

### 5.5 核心函数一览

| 函数 | 职责 |
| --- | --- |
| `read_file` | 读取文件，UTF-8 失败时回退 GBK |
| `clean_text` | 清洗文本，去除标点并统一小写 |
| `tokenize` | 分词，生成单字 / 单词 / 中文 2-gram |
| `build_tfidf_vector` | 构建单文档 TF-IDF 向量 |
| `cosine_similarity` | 计算两个向量的余弦相似度 |
| `calculate_similarity` | 串联全流程，返回重复率 |
| `write_answer` | 以两位小数写入答案文件 |
| `main` | 解析命令行参数，调度全流程 |
